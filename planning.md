# Planning – Git Laboration

## Produktidé
En enkel CLI-baserad todo-lista i C#/.NET. Användaren kan lägga till uppgifter, lista dem 
och markera dem som klara. Data sparas i en lokal JSON-fil.

## User Stories (prioriterad backlog)

| Prioritet | User Story |
|-----------|------------|
| 1 | Som användare vill jag kunna lägga till en uppgift så att jag kan hålla koll på vad som ska göras |
| 2 | Som användare vill jag kunna lista alla uppgifter så att jag ser vad som är kvar |
| 3 | Som användare vill jag kunna markera en uppgift som klar så att jag ser vad som är gjort |
| 4 | Som användare vill jag kunna ta bort en uppgift så att listan hålls ren |
| 5 | Som användare vill jag se en sammanfattning (hur många kvar / klara) så att jag snabbt får en överblick |

## Avgränsning
Vi fokuserar på att samarbeta väl i Git och leverera en fungerande grundversion — inte ett komplett system.
